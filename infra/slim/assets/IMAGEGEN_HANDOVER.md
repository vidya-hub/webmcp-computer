## How the assets are consumed (context, no action needed)

- Wallpapers install to `/usr/share/backgrounds/webmcp/` and are applied live by the
  `computer_set_wallpaper` WebMCP tool through pcmanfm.
- Icons install to `/usr/share/webmcp/icons/` and are referenced by absolute path from
`.desktop` launchers in the in-VNC tint2 dock (`/usr/share/webmcp/launchers/`), so
they render with no icon theme installed.
